# 第二步：代码侧收尾与验收记录

日期：2026-09-21。对象：当前「琥珀荒境」小游戏。候选版本：1.0.12（49）。

## 结论与边界

代码收尾、自动化回归、iOS 开发签名构建已完成；已覆盖安装到 iPhone X。**不等于已经完成正式 IPA 验收或所有真机业务验收。** 本轮未提交 App Store、未购买、未新建线上账号、未卸载游戏或清空手机存档。

## 1. 首局与礼包

- 原流程关闭新手礼包后立即弹每周礼包；现合并成一个自选商品页面。顶部「关闭」和底部「先去营地 · 不购买」始终可见，触控区域至少 44px。
- 保留营地「礼包」入口和两个商品；不改变商品、价格档位、限购规则和发货条件。没有取消付费功能，也没有把付费商品写成免费领取。
- 新手及当周展示标记一次性保存，兼容原 `offerPrompts` 字段；关闭后不连续弹窗，回营地不重复展示。下周仍可提示一次。
- 离开营地、打开其他窗口或发生异步存档延迟时，不让礼包覆盖玩家刚打开的操作界面。
- 第一关领奖后明确提示：用材料找行商买卡，再从山口出征，不需要购买付费礼包。

## 2. 构建与资源一致性

- `build-emberwild-ios.mjs` / `verify-emberwild-ios.sh` 现校验源码和打包目录的完整清单及 SHA-256，包含 **89 个图片、音频等 assets 文件**；不再只校验顶层 JS/CSS/HTML。
- 新增资源未打包、资源被覆盖或缺失、打包目录混入旧文件、资源软链接均阻止后续构建。发现多余文件只报错，不自动删除未知文件。
- `audit-emberwild-app.mjs` 检查实际编译的 `.app`：Bundle ID、版本/构建号、134 个游戏文件、两个本地 HTML 的经典脚本入口、旧跑酷文件和旧原生音乐字符串。
- 本次编译目录未发现原跑酷入口文件、恐龙精灵、旧跑酷音频目录；不代表已对全部第三方内容做相似度或权属鉴定。
- 真机日志发现原生音乐预加载仍指向已移除的 `canopy-afternoon.mp3` / `canopy-hop.m4a`。已改用现有荒境营地/战斗音乐，保留 `menu/game` 桥接别名和生命周期行为。
- 默认构建号由旧值 17 更新为候选 49，营销版本保持 1.0.12。上传前仍需确认 App Store Connect 没有占用 49；没有访问后台或宣称已上传。

### 不改动的核心

本轮开始/结束 SHA-256 对比一致：`StoreKitManager.swift`、`BackendGateway.swift`、`PayRequest.swift`、支付诊断控制器、`TrustedWebView.swift` 及支付/分析/Web 代理桥。未改 SDK、主游戏、服务器地址、内容模式、登录权限或支付协议。存档 schema/键名未变。

## 4. 尚未完成，不能标记通过

最终安装回执：10:15（UTC+8），Xcode 显示 `Running PrehistoricBeastmaster on iPhone X`，进程 1052。新进程日志确认 `PBM-MUSIC prepared both tracks in 393 ms`，以及启动完成/1 秒后/4 秒后 `gameBootReady=true`、`authCallbackInstalled=true`。音乐加载错误已消失；这不替代完整听感或战斗体验验收。

1. **正式签名 IPA**：当前钥匙串没有可用的 Apple Distribution 签名身份，Xcode 也未找到当前配置指定的发布描述文件。需要恢复对应发布证书及私钥/有效 profile 后，Archive → 导出 IPA → 对最终解包 `.app` 再执行资源审计。不把无签名 Release `.app` 当成正式包交付。
2. **真实新账号业务**：UI 与桥接测试通过，但本轮没有创建线上账号。最终测试需以专用新测试账号确认注册/登录/重启登录态，勿删除现有玩家存档来模拟新玩家。
3. **真机完整体验**：首局自动化不等于真机长时间触摸/音频体验。手机上需补验摇杆与技能同时操作、拖卡落点、锁屏/切后台恢复、材料购买、领奖和重启存档。
4. **沙盒支付发货**：需专用沙盒账号确认取消不发货，成功后仅发一次，延迟/恢复不误报到账、周礼包限购准确。操作者确认后再购买，本轮没有自动付款。
5. **正式环境一致性**：现有 Debug 的内容配置地址仍是本机 `127.0.0.1:8080`，手机日志有连接拒绝，随后使用现有本地入口回退；Release 使用正式 HTTPS 配置。本轮没有替运营切换小游戏/主游戏模式，不能把 Debug 回退行为算作正式配置验证。真机同时有第三方统计服务超时，不把它等同于支付失败，也不视为已验证埋点送达。
