# 琥珀荒境 / Emberwild

独立小游戏可玩原型，2026-09-17。

本目录没有接入正式 iOS 容器，不替换现有跑酷小游戏，不调用原生桥、登录、支付、埋点或后端接口。没有修改主游戏、Android 或提交审核配置。

## 试玩

在本目录运行 `node serve.cjs`，打开 <http://127.0.0.1:8765>。

本机 Node 位于 `/Users/yukang/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`。预览服务器只监听本机，不向局域网或公网开放。仅双击 HTML 不适用于 ES modules，需要使用本地服务器。

- 手机式操作：左下摇杆移动，所携主武器自动锁定攻击；右下使用「贯骨齐射」「荒骨震击」与冲刺。新远征在营地五选一主武器，旧双武器存档仍可用按钮切换。
- 电脑：WASD / 方向键移动，J 使用贯骨齐射，K 使用荒骨震击，空格冲刺；旧双武器存档可按 Q 切换武器，靠近地图事件后按 E 互动。
- 建造：拖卡到空地放手；也可点卡再点战场。数字 1–4 选择卡牌，Esc 取消选择/拖拽。
- 拖拽时显示放置预览、攻击范围和放置错误原因；手机预览上移 55px，避免手指遮挡。
- 同类建筑上落卡升级，最高三级，并修复耐久。使用卡牌只扣一张库存，不额外扣材料；失败放置、取消、冷却内重复松手不扣卡。
- 战斗中拖卡/选卡进入 15% 速度，卡牌取消后恢复。停止输入或切后台自动暂停。
- 敌人死亡掉琥珀；晶矿可用五种主武器攻击采集；波次结束自动回收掉落，奖励木材、兽骨与琥珀，直接进入休整，不再三选一。新手引导的第一关会明确要求点击「领取奖励」，之后恢复自动入包。
- 点击召喚獸潮开始；八张战斗地图现在拥有固定关卡目标：守蛋、护送采集师、摧毁三座兽巢、50 秒限时采矿、营救弓手、首领守护、守住三处据点和泰坦最终守护。第 3、6、8 关分别迎战沼泽母兽、骨甲冲角兽和琥珀泰坦；猎人、关键 NPC、圣兽卵或据点失守都会按本关规则判负。
- 背景音乐内置于 `assets/audio/`：用户提供的 `Warmth_of_a_Primeval_Dawn.mp3` 用于首页、营地、路线选择、休整商人和结算；`Hold_the_Ridge.mp3` 用于战场（含备战、兽潮和波间整备）。首次点击、触摸或按键后循环播放，两首歌互斥切换并各自保留播放位置，回营地续播家园音乐。暂停、战斗设置/读档确认、切后台、窗口失焦和原生容器停用时停止播放；战斗需点击继续才恢复音乐。音频失败不影响游戏。
- 设置中的「聲音音量」和 ♪ 静音按钮同时控制音乐与合成音效，沿用本机已保存的音量（新用户默认 65%），音乐以较低混音音量播放。音频完全本地加载，不依赖桌面原始文件，不改动游戏进度。
- 首页「前往營地」进入永久基地；战斗暂停菜单可「儲存並回營地」，下次继续原远征。
- 营地保持俯视角，不是横版：WASD / 方向键或手机摇杆自由移动，Shift / 按住「快步」加速，走近设施按 E /「互動」。也可以点地面寻路；路标引导实际步行，不会传送或远程购物。
- 营地右上角可孵化与切换圣兽伙伴。初始圣兽卵免费；潮汐角龙需要一级温室与 3 点孵化热度，岩甲幼龙需要二级温室与 5 点热度。伙伴会跟随、自动索敌、攻击并独立升级，等级和经验跨远征保留。

## 本轮的特色

战斗页已完成一轮上线观感打磨：猎人与圣兽卵使用动态生命条，八关路线常驻显示，兽潮阶段显示实时威胁数量；卡牌增加职责标签、键盘序号、属性色与库存状态，并补充波次入场、弩台枪口焰和投兽器扬尘反馈。手机竖屏会压缩战场高度以确保卡组与下一关按钮无需滚动即可操作。

第二轮战斗打磨：开场战术提示在 3.5 秒后让出视野，保留实时敌人数；冲刺用环形冷却、持续攻击用按压状态反馈，低生命与兽卵危险状态有独立提示。每关胜利在战场顶部列出实际入包的木材、兽骨、琥珀（包含自动回收掉落，受容量上限约束），可收起或直接找商人，不暂停、不强制购物，也不再次发奖励。弩台修正发射原点的瞄准偏差，发射后坐与真正开火同步；骨墙、泉水与旧卡建筑统一使用现有手绘素材，存档和碰撞规则不变。

1. **卡牌即库存物资**：向商人购买指定卡片，拖卡建造或升级；用完需自行补货，没有随机补牌。
2. **猎脊弩台**：开局高速单体火力，逐级提高伤害；三级骨弩箭可连续穿透两名敌人。
3. **琥珀投兽器**：慢速抛物线锁定兽群密集处，落地造成范围伤害与减速，和弩台形成清晰分工。
4. **裂骨墙 × 冲刺**：以牺牲墙体换取范围骨片爆破，不是单纯堆建筑攻击力。
5. **潮汐泉 × 冲刺**：泉边冲刺释放寒潮，治疗、控场与闪避互相配合。
6. **雇佣旅伴**：购买弓手/盾卫契约并拖入战场，旅伴会跟随、攻击并承受伤害，与建筑和玩家共同作战。
7. **自由购买强化**：原来的随机进化改为商人的固定技能货架，全部使用兽骨与琥珀购买，不采用战后随机三选一。
8. **双主动技能成长**：贯骨齐射可依次成长为 7 矛、9 矛并增加穿透；荒骨震击可留下持续减速区，再成长为范围更大、持续 6 秒且每秒造成伤害的地脉回响。每条路线均须按阶购买。
9. **圣兽伙伴成长**：焰脊迅龙高速近战并以第四击引爆焰爪；潮汐角龙远程缓速并治疗猎人与灵巢；岩甲幼龙主动吸引火力、减伤并释放晶甲震波。伙伴阵亡后会在下一关恢复，击败敌人获得永久经验，最高 10 级。
10. **Boss 专属机制**：沼泽母兽、骨甲冲角兽与琥珀泰坦都有三阶段变化、范围预警和两轮召唤；孵化囊、裂角肩甲、琥珀核心会在特定招式中暴露，可被锁定破坏并打断或永久削弱对应能力。
11. **随机地图事件**：每次远征都会把荒境行商、古兽遗迹、受伤猎人、荒野宝箱和精英兽群随机分配到五个不同关卡与落点；路线图会显示事件徽记，战场靠近后可按 E 或触控互动。事件结果与领取状态进入存档，读档不会刷新奖励。
12. **卡组与出征配置**：营地右上角可配置本次携带的 3 张建造卡、1 张佣兵卡、1 把主武器和 1 个主动技能。新远征建立时固化配置；进行中的远征不会被营地后续修改覆盖，旧存档仍按原装备继续。
13. **五武器锻造**：骨矛、骨斧、猎骨弓、裂牙双刃与震骨重锤拥有不同射程、节奏和命中形态；行商新增独立「武器锻造」页，材料解锁三叉矛、环身斧、第三箭扇射、第四击突进环斩或地裂波，不用纯数值升级冒充新招式。
14. **持续成长营地**：永久设施根据已完成关卡积累木材、兽骨、琥珀或孵化热度，玩家须走近设施领取；资源可支持下一次新远征或孵化伙伴。建筑等级同时开放新武器和商人货架，移动居民会发布可重复完成的建设与猎杀委托。
15. **首次必修引导**：新存档只有开始/继续教程一个游戏入口，营地、配置和商人均未开放。遮罩聚焦、循环手势、指定操作和落点吸附逐步教学；不可跳过或放弃，领完奖励才解锁自由操作。毕业后可独立重玩。

## 新手引导

新存档从首页直接进入第一关必修教程，不能先去营地、改装备、逛商人或选其他关卡。移动练习只开放向右走入目标圈；自动攻击必须由主武器实际命中两次；技能播放效果后再确认；建造只开放指定卡和落点圈，圈内落点自动吸附，失败拖放不扣卡。每步成功后冻结时间，确认后才开启下一步。UI 拦截与引擎校验共同限制无关操作。

必修教程全程保护猎人与防线，前四步练习兽站定、伙伴与建筑不抢目标。建造之后不是自由战斗：玩家只观察自动防线，剩余练习兽缩为两只，不开放事件、额外建造、冲刺或技能。清场后只开放领取奖励，领取与存档原子提交；写入失败仍保持必修状态，重试不重复发奖。成功领取后返回营地，才开放配置、商人和自由远征。

必修教程没有跳过、回营地或放弃入口；暂停仅能继续当前步骤。刷新/关闭后以同一远征和步骤恢复，不通过刷新绕过。毕业玩家和旧版已完成/跳过者保留原进度，旧教学快照继续兼容。只有毕业玩家能进入独立「新手试炼」，该可选练习仍不修改正式存档。竖屏和横屏教学均同屏可操作，旋转屏幕后落点与手势同步定位。

### 本地清档验收

`acceptance-reset.json` 是显式、带有效期的一次性验收指令，仅对 `http://127.0.0.1:4174` 的普通网页入口生效，QA 测试入口不执行。刷新时先将三个进度键（主档、自动备份、旧版档）写入并验证 `emberwild_acceptance_backup_<id>`，再清除原进度键；音画设置和其他键不受影响。`emberwild_acceptance_reset_v1` 记录已执行的指令，后续刷新不会重复清档。指令过期或关闭后不会重置新浏览器。旧档的原始字符串保留在独立备份的 `records` 中，可按原存档格式导出恢复；备份失败时停止清档并显示重试提示。清档发生在用户浏览器加载网页时，不是删除整个浏览器配置目录。

基础内容：8 关路线、3 套战场环境、5 种武器、6 类建筑卡、2 类雇佣卡、19 项商人强化（含五种武器改招与双主动技能各两阶成长）、3 种普通敌人、3 个机制不同的首领。晶矿位置与敌人入场方位随机；商人商品和价格不随机。完整成长曲线、经济和自动实战基线见 [BALANCE.md](./BALANCE.md)。

这是一局数分钟的快速验证版本，尚未扩展为原先设想的 8–12 分钟正式内容。战场建筑当前不能手动搬迁/出售；永久营地建筑支持免费搬迁。没有复刻外部游戏代码、角色、界面或资源。

## 材料与商人

在战场准备阶段或每波胜利后点击「找商人」。战斗期间不交易，但可以使用已购买的卡。不会强制打开商店，玩家可以跳过购物直接迎接下一波。

- 初始旅行补给：木材 8、兽骨 4、琥珀 16。默认配置为弩台、投兽器、骨墙与弓手；弩台带 2 张，其余已选建造卡和佣兵卡各带 1 张。玩家可在营地改为任意 3 建造 + 1 佣兵组合。
- 八关固定奖励逐步由 `木材 5 / 兽骨 2 / 琥珀 3` 增长到 `木材 8 / 兽骨 5 / 琥珀 6`；另回收战场掉落。每关结束主角与圣兽卵各恢复 12，建筑恢复最大耐久的 20%。同一关不重复结算。
- 建筑卡使用木材和兽骨购买；雇佣卡另需琥珀。点击「建造卡 / 雇佣卡」切换快捷栏，每次部署或建筑升级消耗一张，不重复收费。
- 弓手远程射击，盾卫近战接敌；战场最多十二座建筑、四名佣兵。阵亡不返还契约。
- 「武器锻造」只展示本次携带主武器的改招方案，消耗木材 3–5、兽骨 3–5、琥珀 12–14；「技能成长」保留主动技能与卡牌强化。齐射与震击各有两阶专属成长，第一阶需兽骨 2、琥珀 10，第二阶需兽骨 4、琥珀 16。每项本次远征只买一次，购买即生效。
- 材料、库存、部署的佣兵、已买强化随本次远征存档保留。远征内剩余材料不会直接带回；永久设施产出与 NPC 委托奖励会进入营地仓储，木材、兽骨、琥珀在建立下一次新远征时一次性装载并从仓储扣除，孵化热度留在营地使用。
- 购买与存档一起完成；存储失败会退回购买前的材料和库存并显示重试提示。材料不足、库存满、无效放置和佣兵满员不会扣款或扣卡。

## 永久营地

营地是独立的 2000×1700 俯视场景，保留上下左右自由移动，镜头双轴跟随。搬运工走补给路线、猎人巡逻，在目的地停留，遇玩家会让路；两人头顶会显示委托状态，走近即可查看或交付。商人留在摊位、铁匠留在工位，已选择的圣兽伙伴会跟随玩家，尚未孵化时营火旁保留圣兽卵。营火、池水与工坊烟气会动；建筑、营火和摊位有碰撞，点地面寻路会绕行。

走近六块空地之一，按「互動」选择永久建筑蓝图；走近已建设施查看、升级或选择搬迁，再步行到空地确认安置。四类设施每类限一座、最高三级，搬迁免费。**战场的卡牌拖拽建造保留不变**；营地建设改为就近互动，不再是可远程拖拽的格子面板。

营地右上角「出征配置」用于编辑下一次远征卡组；必须选满 3 张建造卡、1 张佣兵卡、1 把武器和 1 个主动技能才能保存。骨矛与骨斧默认可用，工坊一至三级依次开放猎骨弓、裂牙双刃和震骨重锤。走近行商后只会看到该配置及设施等级已经解锁的卡牌与强化。第一次备货会先建立本次远征准备存档、套用营地加成、装载仓储资源并固化配置，购买后仍留在营地，走到东北山口才进入战斗；购物不会重复创建远征。已有战斗尚在兽潮阶段时不能借回营地绕过商店限制。营火可查看营地效果、仓储与记录。

设施产出只按已结算的完成关卡计算，不依赖现实时间，失败远征的已完成关卡也有效；待领取量最多累计 99。搬运工委托要求建造或升级一次设施，奖励木材 3、琥珀 1、营火石 1；巡林猎人委托从累计击败 20 名敌人开始，每轮提高 5、最多 50，奖励兽骨 4、琥珀 2、营火石 1。交付后两项委托都会重复发布。

位置、建筑、交易与战斗共享原有存档。对话期间暂停移动，失焦/切后台/触摸中断会清除输入。点路标只是自动步行，仍须到达并互动。重开营地恢复上次位置；旧存档缺少位置时从中央营地出生。

| 设施 | 每级效果与生产 | 等级解锁 | 建造 / 二级 / 三级消耗 |
| --- | --- | --- | --- |
| 猎人帐篷 | 出征生命 +10；每完成 2 关生产木材 × 等级 | 护甲 / 巨兽之心 / 踏风步 | 3 / 5 / 8 营火石 |
| 骨器工坊 | 武器伤害 +5%；每完成 3 关生产兽骨 × 等级 | 猎骨弓 / 裂牙双刃 / 震骨重锤 | 4 / 6 / 9 营火石 |
| 补给仓库 | 出征琥珀 +2；每完成 4 关生产琥珀 × 等级 | 工匠 / 拾荒 / 守巢商品 | 3 / 5 / 8 营火石 |
| 兽卵温室 | 兽卵耐久 +15；每完成 3 关生产热度 × 等级 | 一级潮汐角龙；二级岩甲幼龙 | 3 / 5 / 8 营火石 |

首次获得 8 营火石。胜负结算时，每完成一关奖励 2 营火石，八关通关额外奖励 8；主动放弃不奖励。胜利界面会逐项列出营火石、木材、兽骨和琥珀：营火石写入永久营地，后三项明确标注为远征结束时的本局持有量。奖励和结束远征在同一份存档中提交，重复结算不重复发放。战败不清空永久营地。

营地加成只在新远征开始时应用一次。暂存远征期间升级营地，不会改变已经保存的战斗；读档也不会重复叠加属性。

## 手绘游戏美术

## 存档与隔离

使用当前浏览器的 `localStorage`，不读取或修改原跑酷存档。**这是本机存档，不是账号或云端同步。** 更换浏览器、访问地址或设备不会自动同步；清除网站资料会丢失本机进度，请先「匯出存檔」。导入 JSON 前会校验并明确要求确认替换。

- 每 2.5 秒、关键操作、暂停以及页面隐藏/离开时保存；顶部「存」按钮可手动保存。系统强制终止浏览器时可能来不及执行最后一次保存，以最近成功的检查点为准。
- 保存生命、敌人和生成队列、建筑、卡牌库存、快捷栏、佣兵、圣兽伙伴等级/经验、材料、已买强化、掉落、随机数状态等；刷新或重开后可继续。恢复后先暂停，离线期间不推进战斗，不重复发放材料。
- `emberwild_save_v2` 为当前存档，`emberwild_save_v2_backup` 保留上一份有效记录，包含版本、校验和和修订号。校验用于检测损坏，不是反作弊或加密机制。
- 存储键不变，封装版本升级到 10，增加必修标记并保留此前引导与营地字段，战斗快照仍为版本 2。可读旧封装 2–9；旧三选一阶段迁移到休整，不补发已结算奖励。旧版页面不能将新格式静默降级。
- 首次读取旧键 `emberwild_prototype_v1` 时迁移统计记录，不删除旧键。旧版没有战斗快照，因此只能迁移统计。
- 当前记录损坏时尝试读取上一份备份并显示提示；未知的新版本或无法恢复的记录不会被静默覆盖。
- 多页同时运行时，使用 Web Locks（浏览器支持时）和写前一致性检查；另一页更新进度会暂停旧页，要求载入最新记录，避免旧页覆盖新进度。
- 存储不可用或空间不足时明确显示失败，暂停战斗；营地建设保存失败不扣资源。不会把失败显示成「已存档」。

不申请任何系统权限，没有用户跟踪或网络上报。本地预览资源请求外无网络访问。QA hook 仅在 localhost / 127.0.0.1 且 `?qa=1` 时启用，正常预览不启用。
