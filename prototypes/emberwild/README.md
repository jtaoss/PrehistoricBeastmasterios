# 琥珀荒境 / Emberwild

独立小游戏可玩原型，2026-09-17。

本目录没有接入正式 iOS 容器，不替换现有跑酷小游戏，不调用原生桥、登录、支付、埋点或后端接口。没有修改主游戏、Android 或提交审核配置。

## 试玩

在本目录运行 `node serve.cjs`，打开 <http://127.0.0.1:8765>。

本机 Node 位于 `/Users/yukang/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`。预览服务器只监听本机，不向局域网或公网开放。仅双击 HTML 不适用于 ES modules，需要使用本地服务器。

- 手机式操作：左下摇杆移动，普通攻击自动锁定；右下使用「贯骨齐射」「荒骨震击」与冲刺，按钮切换骨矛与骨斧。
- 电脑：WASD / 方向键移动，J 使用贯骨齐射，K 使用荒骨震击，空格冲刺，Q 切换武器。
- 建造：拖卡到空地放手；也可点卡再点战场。数字 1–4 选择卡牌，Esc 取消选择/拖拽。
- 拖拽时显示放置预览、攻击范围和放置错误原因；手机预览上移 55px，避免手指遮挡。
- 同类建筑上落卡升级，最高三级，并修复耐久。使用卡牌只扣一张库存，不额外扣材料；失败放置、取消、冷却内重复松手不扣卡。
- 战斗中拖卡/选卡进入 15% 速度，卡牌取消后恢复。停止输入或切后台自动暂停。
- 敌人死亡掉琥珀；晶矿可用两种武器攻击采集；波次结束自动回收掉落，奖励木材、兽骨与琥珀，直接进入休整，不再三选一。
- 点击召喚獸潮开始；远征扩展为八张战斗地图。第 3、6、8 关分别迎战沼泽母兽、骨甲冲角兽和琥珀泰坦；生命或圣兽卵耐久归零失败，击败八关胜利。
- 音效默认关闭，♪ 按钮开启；音效由 Web Audio 合成，无外部音频资源。
- 首页「前往營地」进入永久基地；战斗暂停菜单可「儲存並回營地」，下次继续原远征。
- 营地保持俯视角，不是横版：WASD / 方向键或手机摇杆自由移动，Shift / 按住「快步」加速，走近设施按 E /「互動」。也可以点地面寻路；路标引导实际步行，不会传送或远程购物。

## 本轮的特色

战斗页已完成一轮上线观感打磨：猎人与圣兽卵使用动态生命条，八关路线常驻显示，兽潮阶段显示实时威胁数量；卡牌增加职责标签、键盘序号、属性色与库存状态，并补充波次入场、弩台枪口焰和投兽器扬尘反馈。手机竖屏会压缩战场高度以确保卡组与下一关按钮无需滚动即可操作。

第二轮战斗打磨：开场战术提示在 3.5 秒后让出视野，保留实时敌人数；冲刺用环形冷却、持续攻击用按压状态反馈，低生命与兽卵危险状态有独立提示。每关胜利在战场顶部列出实际入包的木材、兽骨、琥珀（包含自动回收掉落，受容量上限约束），可收起或直接找商人，不暂停、不强制购物，也不再次发奖励。弩台修正发射原点的瞄准偏差，发射后坐与真正开火同步；骨墙、泉水与旧卡建筑统一使用现有手绘素材，存档和碰撞规则不变。

1. **卡牌即库存物资**：向商人购买指定卡片，拖卡建造或升级；用完需自行补货，没有随机补牌。
2. **猎脊弩台**：开局高速单体火力，逐级提高伤害；三级骨弩箭可连续穿透两名敌人。
3. **琥珀投兽器**：慢速抛物线锁定兽群密集处，落地造成范围伤害与减速，和弩台形成清晰分工。
4. **裂骨墙 × 冲刺**：以牺牲墙体换取范围骨片爆破，不是单纯堆建筑攻击力。
5. **潮汐泉 × 冲刺**：泉边冲刺释放寒潮，治疗、控场与闪避互相配合。
6. **雇佣旅伴**：购买弓手/盾卫契约并拖入战场，旅伴会跟随、攻击并承受伤害，与建筑和玩家共同作战。
7. **自由购买强化**：原来的 12 项随机进化改为商人的固定武技货架，每项本局限购一次。
8. **自动攻击 × 双主动技能**：普通攻击自动选择射程内最近目标；贯骨齐射负责远程扇形穿透，荒骨震击负责近身范围伤害、减速与短暂无敌。晶矿在靠近后也会自动采集。

基础内容：8 关路线、3 套战场环境、2 种武器、4 类建筑卡、2 类雇佣卡、12 项商人强化、3 种普通敌人、3 个机制不同的首领。晶矿位置与敌人入场方位随机；商人商品和价格不随机。完整成长曲线、经济和自动实战基线见 [BALANCE.md](./BALANCE.md)。

这是一局数分钟的快速验证版本，尚未扩展为原先设想的 8–12 分钟正式内容。战场建筑当前不能手动搬迁/出售；永久营地建筑支持免费搬迁。没有复刻外部游戏代码、角色、界面或资源。

## 材料与商人

在战场准备阶段或每波胜利后点击「找商人」。战斗期间不交易，但可以使用已购买的卡。不会强制打开商店，玩家可以跳过购物直接迎接下一波。

- 初始旅行补给：木材 8、兽骨 4、琥珀 16，以及猎脊弩台 2、琥珀投兽器 1、骨墙 1、泉水 1 张。初始建造快捷栏固定为这四类卡。
- 八关固定奖励逐步由 `木材 5 / 兽骨 2 / 琥珀 3` 增长到 `木材 8 / 兽骨 5 / 琥珀 6`；另回收战场掉落。每关结束主角与圣兽卵各恢复 12，建筑恢复最大耐久的 20%。同一关不重复结算。
- 建筑卡使用木材和兽骨购买；雇佣卡另需琥珀。点击「建造卡 / 雇佣卡」切换快捷栏，每次部署或建筑升级消耗一张，不重复收费。
- 弓手远程射击，盾卫近战接敌；战场最多十二座建筑、四名佣兵。阵亡不返还契约。
- 强化固定展示全部 12 项，按强度需要兽骨 2–4、琥珀 14–18；每项本次远征只买一次，购买即生效。
- 材料、库存、部署的佣兵、已买强化随本次远征存档保留。**当前版不跨远征继承这些物资**；永久营地仍使用独立的营火石结算成长。
- 购买与存档一起完成；存储失败会退回购买前的材料和库存并显示重试提示。材料不足、库存满、无效放置和佣兵满员不会扣款或扣卡。

## 永久营地

营地是独立的 2000×1700 俯视场景，保留上下左右自由移动，镜头双轴跟随。搬运工走补给路线、弓手巡逻，在目的地停留，遇玩家会让路；商人留在摊位、铁匠留在工位，幼兽暂留在营火旁。营火、池水与工坊烟气会动；装饰 NPC 暂不提供独立任务。建筑、营火和摊位有碰撞，点地面寻路会绕行。

走近六块空地之一，按「互動」选择永久建筑蓝图；走近已建设施查看、升级或选择搬迁，再步行到空地确认安置。四类设施每类限一座、最高三级，搬迁免费。**战场的卡牌拖拽建造保留不变**；营地建设改为就近互动，不再是可远程拖拽的格子面板。

走近行商可以自由购买战场建造卡、雇佣卡和武技。第一次备货会先建立本次远征准备存档、套用营地加成，购买后仍留在营地，走到东北山口才进入战斗；购物不会重复创建远征。已有战斗尚在兽潮阶段时不能借回营地绕过商店限制。营火可查看营地效果与记录。

位置、建筑、交易与战斗共享原有存档。对话期间暂停移动，失焦/切后台/触摸中断会清除输入。点路标只是自动步行，仍须到达并互动。重开营地恢复上次位置；旧存档缺少位置时从中央营地出生。

| 设施 | 每级效果 | 建造 / 二级 / 三级消耗 |
| --- | --- | --- |
| 猎人帐篷 | 出征生命 +10 | 3 / 5 / 8 营火石 |
| 骨器工坊 | 武器伤害 +5% | 4 / 6 / 9 营火石 |
| 补给仓库 | 出征琥珀 +2 | 3 / 5 / 8 营火石 |
| 兽卵温室 | 兽卵耐久 +15 | 3 / 5 / 8 营火石 |

首次获得 8 营火石。胜负结算时，每完成一关奖励 2 营火石，八关通关额外奖励 8；主动放弃不奖励。胜利界面会逐项列出营火石、木材、兽骨和琥珀：营火石写入永久营地，后三项明确标注为远征结束时的本局持有量。奖励和结束远征在同一份存档中提交，重复结算不重复发放。战败不清空永久营地。

营地加成只在新远征开始时应用一次。暂存远征期间升级营地，不会改变已经保存的战斗；读档也不会重复叠加属性。

## 手绘游戏美术

本轮使用内置 ImageGen 生成透明 PNG 图集，统一为青绿披风、兽骨武器、木骨营地的荒野 RPG 风格。完整提示词与素材说明见 [PROMPTS.md](assets/painted-v1/PROMPTS.md)。没有用生图替代游戏画面截图；图片实际接入 Canvas 场景和设施/商人界面。

- 主角已重新生成为年轻、紧凑比例的荒野驯兽师，使用独立的五帧待机、五帧轻快疾行、五帧骨矛和五帧骨斧动作。待机保持双脚着地，只做呼吸、眨眼和极轻微重心变化；移动按实际距离播放，不再使用跑步首帧冒充站立，也不对腿部做程序拉伸。所有帧使用固定人物缩放并校准脚底，移动停下先经过落脚阶段再进入缓慢待机循环；朝向有阈值防抖，竖直走路保持左右朝向。
- 四类怪物保留原有识别造型，并按物种增加位移驱动的跑动起伏、攻击蓄力与短冲、受击压缩和死亡倒地淡出；这些表现只改变渲染，不改变伤害、攻击范围或碰撞体。
- 胜负结算改为完整奖励面板：显示关卡进度、评级、波次与首领奖励拆分、击败/连携统计和营火石总奖励，并保留返回营地与再次远征的明确入口。
- 帐篷、工坊、仓库、温室、商人摊位与山口使用独立设施图块；营火、树木、岩石、蕨叶、居民、佣兵和幼兽使用同风格素材。
- 战场核心目标已换成独立透明的 AI 手绘圣兽恐龙蛋：象牙斑纹蛋壳置于骨木孵化巢内，以克制的琥珀呼吸光强化可守护目标；图片加载失败时仍保留原几何蛋作为兜底。
- 战场琥珀矿点已由黄色几何块替换为透明 AI 手绘晶簇，并按地图坐标产生轻微尺寸与角度差异；只改变渲染，不改变采集血量、命中范围或琥珀奖励。
- 保留俯视自由移动、前后遮挡、碰撞、就近交易、建造和存档。移动 NPC 使用工作路线和停留，不再按正弦轨迹漂移；对话/失焦时跟随游戏时钟暂停，不新增存档字段。
- 五张场景图集和三张角色动作图集共用图片缓存，原始 PNG 保持不变；不在逐帧循环创建图片。动作图集加载失败时退回旧图块，场景图片加载失败时使用几何绘制兜底。
- 原动作素材见 [motion-v2/PROMPTS.md](assets/motion-v2/PROMPTS.md) 与 [motion-v3/PROMPTS.md](assets/motion-v3/PROMPTS.md)；当前年轻主角三套动作和完整 ImageGen 提示词见 [motion-v4/PROMPTS.md](assets/motion-v4/PROMPTS.md)。当前是正反两面逐帧动画，通过镜像覆盖左右方向，并非完整八方向制作；铁匠与行商以站立为主，盾卫仍用旧姿势，后续可继续补专用工作/攻击动作。
- 初始四张建筑卡均使用独立高分辨率透明美术；新猎脊弩台和琥珀投兽器的同一份美术会同时出现在卡牌与战场本体，战斗分别具有骨弩箭和琥珀抛物线。旧火炬/兽巢逻辑仅为既有本机存档兼容保留，不进入新局商店；雇佣卡仍由原图集提供。真实 iPhone 的加载耗时、内存及帧率尚待实测。

## 存档与隔离

使用当前浏览器的 `localStorage`，不读取或修改原跑酷存档。**这是本机存档，不是账号或云端同步。** 更换浏览器、访问地址或设备不会自动同步；清除网站资料会丢失本机进度，请先「匯出存檔」。导入 JSON 前会校验并明确要求确认替换。

- 每 2.5 秒、关键操作、暂停以及页面隐藏/离开时保存；顶部「存」按钮可手动保存。系统强制终止浏览器时可能来不及执行最后一次保存，以最近成功的检查点为准。
- 保存生命、敌人和生成队列、建筑、卡牌库存、快捷栏、佣兵、材料、已买强化、掉落、随机数状态等；刷新或重开后可继续。恢复后先暂停，离线期间不推进战斗，不重复发放材料。
- `emberwild_save_v2` 为当前存档，`emberwild_save_v2_backup` 保留上一份有效记录，包含版本、校验和和修订号。校验用于检测损坏，不是反作弊或加密机制。
- 存储键不变，封装版本升级到 4（新增营地坐标），战斗快照仍为版本 2。可读旧封装 2 / 3；旧三选一阶段迁移到休整，保留已学强化与已结算资源，不再补发该波奖励。旧版页面不能将新格式静默降级。
- 首次读取旧键 `emberwild_prototype_v1` 时迁移统计记录，不删除旧键。旧版没有战斗快照，因此只能迁移统计。
- 当前记录损坏时尝试读取上一份备份并显示提示；未知的新版本或无法恢复的记录不会被静默覆盖。
- 多页同时运行时，使用 Web Locks（浏览器支持时）和写前一致性检查；另一页更新进度会暂停旧页，要求载入最新记录，避免旧页覆盖新进度。
- 存储不可用或空间不足时明确显示失败，暂停战斗；营地建设保存失败不扣资源。不会把失败显示成「已存档」。

不申请任何系统权限，没有用户跟踪或网络上报。本地预览资源请求外无网络访问。QA hook 仅在 localhost / 127.0.0.1 且 `?qa=1` 时启用，正常预览不启用。

## 文件

- `engine.mjs`：纯逻辑状态机与战斗模拟。
- `app.mjs`：UI、触摸/键盘/鼠标、音效和存档流程。
- `save.mjs`：版本化存档、备份、迁移、结算、导入导出和写入冲突保护。
- `camp.mjs` / `camp-ui.mjs`：永久营地逻辑、加成、卡牌建造与拖拽操作。
- `camp.css`：移动端营地卡牌与地图的布局调整。
- `merchant-ui.mjs` / `merchant.css`：商人货架、商品分类、材料价格与卡牌库存展示。
- `art.mjs`：原创 Canvas 角色、建筑、战斗特效及 SVG 卡牌图标。
- `painted-art.mjs` / `painted.css`：透明生图图集索引、角色动作/武器图层、界面配图样式。
- `actor-motion.mjs` / `character-art.mjs`：位移驱动动作状态、逐帧图集、脚底/手部锚点与动作素材缓存。
- `camp-residents.mjs`：搬运/巡逻路线、停留、让路及设施变更后重新寻路。
- `camp-world.mjs` / `camp-renderer.mjs`：俯视营地移动、碰撞、寻路与场景绘制。
- `assets/`：内置生图工具生成的封面与场景；见 `ASSET_PROMPTS.md`。
- `assets/painted-v1/`：本轮角色、武器、居民、设施与场景 PNG，`settlement-v2.png` 为实际使用的设施图集，初稿保留备用。
- `test-output/`：本原型测试截图，不是正式 App Store 宣传素材。
